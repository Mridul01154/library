# Library Management System

A comprehensive library management system with book catalog, member management, borrowing/returning, fines, ratings, and reports.

## Features
- 📚 Book catalog with search and filters
- 👥 Member management with fine tracking
- 🔄 Borrow/Return books with automatic fine calculation
- ⭐ Book ratings and reviews
- 📊 Reports and analytics dashboard
- 🌓 Dark/Light mode
- 📥 Export data to CSV

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
